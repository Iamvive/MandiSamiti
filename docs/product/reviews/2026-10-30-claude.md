# Claude review, 2026-10-30 (C1 to C3, F17 start-up)

## What changed
- `INTEREST_RECEIVED` is a new transaction type. It counts as cash in on the day page and the drawer. Party balance does not move: `getPartyBalance` skips `[SETTLE:` rows and never sums this type.
- Repayment writes a principal row and an interest row as one settlement. Voiding the principal row now voids the interest row too (sibling void).
- Money-loan outstanding uses `principalPaisa`, so interest rows no longer shrink the loan.
- `RepayLoanDialog` is used from the party ledger and the loan book. Grain loans keep the weight sheet.
- F17: the app shows an empty screen until trade settings emit, so English users no longer see one Hindi frame. Branch `feat/f17-startup`.

## Device steps for Antigravity (TEST party only)
1. Create a TEST party and a Rs 10,000 money loan backdated 30 days at 2% a month.
2. Repay Rs 1,200. Expect interest Rs 200 and principal Rs 1,000.
3. Lower interest to Rs 100. Expect the hint "हिसाब से Rs 200" and the split to update.
4. Void the principal row. Expect the interest row to void too.
5. Cold start with language set to English. Expect no Hindi flash.
