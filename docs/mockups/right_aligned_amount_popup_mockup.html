How This Works in Compose Architecture

State & Trigger

A simple var showNegativeCashPopup by remember { mutableStateOf(false) } in DrawerSummaryCard.kt. The ⚠️ badge is only visible when state.isNegativeCash.

Popup Mechanism

Rendered as a lightweight AlertDialog or anchored Popup with onOpening() as the primary action. Zero permanent layout shifts or added vertical height on the main screen.
