    Before you judge these

    • B final samples. All slips, the ₹200 interest and the ₹500 deposit are made-up examples. Buy shows a loan and a deposit together so both can be judged; many parties will have only one. Sell keeps its balance display only and is not drawn here. Slip totals use the app's real rule: final rounded to the nearest ₹10, with commission absorbing the rounding.
    • Sample data. Amounts come from the test day in the Phase 1 review, with TEST parties. The one number made up for this page is the ₹1,600 count in the "difference" state, used to show how a shortfall looks.
    • The balanced day close depends on bug P2. The app today opens day close with a false "अंतर: ₹47,885". The balanced moment cannot ship until that is fixed. A real difference gets a plain, neutral treatment, never a celebration.
    • The running बाकी in directions A to C is new display only. B final drops it: with one card per bill and loan there is no row order to run a balance along, so the देना है card states how its figure is made up. In A to C it adds up the same figures the app already holds: ₹22,800, then ₹17,800, then ₹19,800. No money math, schema or stored data changes. Tare and bardana are unchanged in the older directions and removed in B final, as decided on 2026-10-31.
    • Moved in all three: सीखें goes to Settings, voice mute becomes one icon, party initials are replaced by a farmer or merchant icon, which also removes the broken Hindi avatar. Bracketed English is gone from Hindi labels.
    • Stress test: with a long Hindi name and ₹1,24,00,000 in every amount, A and A+ hold at 100% and 200% text. B and C overflow at 200% because of their 36px headline numbers, which need the compact units from NGDL §5.5 (₹1.24 Cr) in any build.
    • Not testable here: haptics, real sunlight, and how it feels on the Redmi. This page runs in a browser. It says nothing about speed in the yard.
    • NGDL: no token change is needed. Two limits shaped the designs. Green and warning colours are too faint for small text in light theme, so coloured amounts are always bold on a white card and warnings use an icon with dark text. NGDL has no on-colour pair for a red fill, so cash out is an outlined button. NGDL also names Inter and JetBrains Mono, which have no Hindi, so these use the same system fonts as the app.
