Negative Cash Warning Options

When cash in drawer is negative (usually because morning opening cash wasn't entered yet), how should we guide the trader without cluttering the screen or looking like an ugly system error?

Option A Zero Extra Height

Inline Status Pill

Replaces the passive "Physical cash not counted" pill with an amber interactive chip right next to the negative amount. Zero vertical space added to the card.

Architecture & Component Responsibility

Option A Code Impact
DrawerSummaryCard.kt

Mutates drawer-status-chip when state.isNegativeCash. No changes to table or screen scaffolding.

Option B Code Impact (Recommended)
DailyCashRegisterScreen.kt

Decorates BahiAnchorRow with amber container when openingCashPaisa == 0L && isNegativeCash. Completely removes warning from DrawerSummaryCard.

Option C Code Impact
DrawerSummaryCard.kt

Appends attached bottom bar to card layout when state.isNegativeCash. Adds 24dp vertical card height.
